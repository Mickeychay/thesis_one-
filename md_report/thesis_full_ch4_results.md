# บทที่ 4: ผลการวิจัย (Research Results)

บทนี้จะนำเสนอผลการประเมินประสิทธิภาพของระบบสืบค้นข้อมูลคู่มือปฏิบัติงานสังคมสงเคราะห์และกระบวนการยุติธรรม โดยเปรียบเทียบระหว่างระบบสืบค้นแบบดั้งเดิม (Baselines) กับระบบที่ได้รับการเสริมประสิทธิภาพด้วยสมการ H2L (Human-to-LLM Taxonomy Reranking) การทดสอบดำเนินการบนชุดข้อมูลมาตรฐานจำนวน 100 กรณีศึกษา (n=100) ซึ่งครอบคลุมทั้งกรณีปกติและกรณีที่ต้องใช้การอนุมานปัญหาแอบแฝง (Implicit Reasoning)

## 4.3 อภิปรายข้อค้นพบทางวิชาการ (Academic Discussion)

จากหลักฐานเชิงประจักษ์ในตารางที่ 4.2 สามารถอภิปรายผลเพื่อตอบคำถามการวิจัย (RQs) ได้ดังนี้:

### 1. การแก้ไขปัญหา False Positives จากบริบทอดีตและบุคคลอื่น (ตอบ RQ1)
กรณีศึกษา `ADV_001` และ `ADV_008` พิสูจน์ให้เห็นจุดบอดที่ร้ายแรงของระบบ Dense Retrieval ทั่วไปที่ใช้เพียง Vector Embeddings ซึ่งมักจะเกิด **False Positive** เมื่อเจอคีย์เวิร์ดที่มีน้ำหนักทางอารมณ์สูง (High-emotion words) เช่น "ฆ่าตัวตาย" หรือ "โรคจิตเภท" แม้ว่าคำเหล่านั้นจะกล่าวถึงเหตุการณ์เมื่อสิบปีก่อน หรือเป็นปัญหาของบุคคลอื่น (ญาติ/พี่ชาย) ก็ตาม 
สมการ H2L สามารถแก้ปัญหานี้ได้อย่างสมบูรณ์ โดยการใช้ **Polarity Gate ($G_{pol}$)** และ **Subject Attribution Filter** ทำให้คะแนน nDCG@10 ในกรณีศึกษาดังกล่าวพุ่งขึ้นจาก `0.0000` เป็น `1.0000` และ `0.9197` ตามลำดับ

### 2. ความเสี่ยงของการมโนคำตอบในแนวคิด HyDE (ตอบ RQ2)
ผลการทดสอบยืนยันว่า กลยุทธ์ HyDE ทำคะแนนภาพรวมต่ำที่สุด (0.0234) เนื่องจากเมื่อเจอเคสซับซ้อนอย่าง `MENTAL_008_PAR_01` โมเดลภาษา (LLM) จะสร้างเอกสารจำลองที่ไม่ตรงกับบริบทความจริง (Hallucination) ส่งผลให้การค้นคืนล้มเหลว งานวิจัยนี้จึงสรุปเป็นข้อเสนอแนะทางวิชาการว่า ในโดเมนสวัสดิการสังคมและสาธารณสุข ห้ามพึ่งพา Zero-shot Generation ของ LLM แต่เพียงลำพัง แต่จำเป็นต้องมี **Human Taxonomy** ของ H2L เป็นรากฐานควบคุมความปลอดภัย (Safety Guardrail)

### 3. การทำงานร่วมกันแบบไดนามิกผ่าน Length Gate ($G_{len}$) (ตอบ RQ3)
สถาปัตยกรรม H2L ใช้ฟังก์ชัน $G_{len}$ ในการปรับสเกลคะแนนตามความยาวและรายละเอียดของเคส หากผู้ใช้อธิบายอาการเพียงสั้นๆ ระบบจะลดบทบาท H2L เพื่อให้ Vector Search ค้นหาเชิงกว้าง แต่หากมีรายละเอียดเคสที่ยาวและซับซ้อน เช่น `MENTAL_008_PAR_01` ฟังก์ชัน $G_{len}$ จะส่งผ่านคะแนน Severity ของรหัส Taxonomy เข้ามาคูณปรับลำดับอย่างเต็มประสิทธิภาพ ช่วยให้ระบบเสถียรและไม่อยู่ในภาวะ Overfitting
